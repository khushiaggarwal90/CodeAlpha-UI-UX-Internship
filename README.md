# 🎨 CodeAlpha UI/UX Design Internship

✨ Welcome to my UI/UX Design Internship Project!

During my CodeAlpha UI/UX Design Internship, I worked on a **Food Delivery App** project using **Figma**. This project gave me an opportunity to explore the UI/UX design process, starting from basic wireframes and gradually developing them into a detailed and visually appealing interface.

---

## 🍕 Project: Food Delivery App

The goal of this project was to design a simple, clean, and user-friendly food delivery experience.

The app includes four main screens:

- 🔐 **Login Screen** – Allows users to log in and access the application.
- 🏠 **Home Screen** – Helps users explore food categories and available food items.
- 🍕 **Food Details Screen** – Displays information about a selected food item, including image, price, rating, and reviews.
- 🛒 **My Cart Screen** – Allows users to review selected items and view the subtotal, delivery fee, and total amount.

---

## 🎯 Task 1 – Wireframing & Low-Fidelity Design

For Task 1, I created **low-fidelity wireframes** to plan the basic structure, layout, screen flow, and user experience of the Food Delivery App.

### 🖥️ Screens
1. Login Screen
2. Home Screen
3. Food Details Screen
4. My Cart Screen

This task helped me understand how an idea can be structured and planned before moving towards the final visual design.

## ✨ Task 2 – High-Fidelity UI Design

For Task 2, I transformed the initial wireframes into a **high-fidelity UI design**.

I added:

- 🎨 Color palettes
- 🔤 Typography
- 🔘 Buttons
- 🖼️ Images
- 🔹 Icons
- 📐 Layout and spacing
- ✨ Visual design elements

The aim was to make the interface more polished, attractive, consistent, and user-friendly.

1. Login Screen
2. Home Screen
3. Food Details Screen
